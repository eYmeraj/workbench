Neovim Pocket Guide

Your config is a deliberately small setup: a fast place to read and fix what agents wrote. It has five leader keys, a git UI, and language servers for TypeScript, Python, Swift, Lua, the web, shell, YAML and Markdown.

Space is the leader key. Press it and pause: a menu lists every leader key, so you don't need to memorize them.

Find and replace across the project

  1. Spaces and type oldName
  2. Ctrl-q sends every match to the quickfix list
  3. Run :cdo s/oldName/newName/g | update to replace in each match and save
  4. ]q and [q step through the list to review

For renaming a variable or function in code, grn is safer: it only changes real uses of that symbol.

Watch out

Things in the config that can surprise you. None of these were changed. Each one has a suggested fix if you want it.

RiskEsc always runs :w

  • In a new unsaved buffer or in :help, it shows an error (E32: No file name, E45: 'readonly' option is set).
  • In Oil, it applies your pending file changes (after a confirmation).
  • In a Neogit commit message, once Esc has saved, q commits right away instead of asking. Cancel with Ctrl-cCtrl-k.
  • Most important with agents: :w writes even when you changed nothing. If an agent edited the file after you opened it, Neovim asks whether to overwrite, and one y wipes the agent's work. :update only writes when you made a change.

Suggested fix, in lua/keys.lua:

vim.keymap.set('n', '<Esc>', function()
  vim.cmd.nohlsearch()  -- also clear search highlight
  if vim.bo.buftype == '' and vim.api.nvim_buf_get_name(0) ~= '' then
    vim.cmd('silent update')
  end
end, { desc = 'Save' })

With this version, Esc no longer applies Oil changes, so use :w there.

MinorReload a file an agent changed

Run :e to reload the current file from disk, or :checktime to check every open file.

Minorgd needs a language server

It's wired to the language server, so in files without one, such as plain text, it finds nothing. In Markdown it follows links. It replaces Neovim's own gd, which jumps to where a name is first declared in the file.

MinorCtrl-a replaces "add 1 to the number"

Neovim normally uses Ctrl-a to increase the number under the cursor (Ctrl-x still decreases it). If you only select all to copy the file, :%y does it in one step.

MinorThe paste mapping isn't needed

Capital P over a selection already pastes without overwriting your clipboard. The mapping does no harm.

MinorThe mouse is off

mouse = '' in lua/vim_config.lua turns it off. mouse = 'a' turns on scrolling and clicking in WezTerm.

Maintenance

Set up Swift for another Xcode project

  1. In the project folder: xcode-build-server config -project Name.xcodeproj -scheme Scheme (xcodebuild -list shows the schemes)
  2. Build once, in Xcode or with xcodebuild -scheme Scheme -destination 'generic/platform=iOS Simulator' build
  3. Keep the generated buildServer.json out of git. It holds paths from this machine. echo buildServer.json >> .git/info/exclude ignores it without touching .gitignore.

After adding files or targets, build again so the server picks them up.

Python virtual environments

pyright uses .venv in the folder that holds pyproject.toml. Without one, third-party imports show as unresolved. uv venv creates it and uv sync installs the project's packages into it. Run :lsp restart afterwards.

Add another language

  1. Find the server's name: each file in ~/.local/share/nvim/lazy/nvim-lspconfig/lsp/ is one server, and its header says how to install it
  2. Add its install command to scripts/17-language-servers.sh and run ./install.sh 17
  3. Add the name to vim.lsp.enable({ ... }) in lua/plugins/lsp.lua
