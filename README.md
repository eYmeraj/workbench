# workbench

My coding setup for macOS: Neovim, WezTerm, zsh, and config for coding agents (Claude Code, Codex, opencode).
Two self-contained copies - pick the one that matches the Mac:

- [`no-admin/`](no-admin/README.md) - no admin access: user-level Homebrew in `~/.brew`, apps in `~/Apps`
- [`admin/`](admin/README.md) - admin access: standard Homebrew in `/opt/homebrew`, apps in `/Applications`

The configs under each `home/` are separate copies; a change you want on both has to be made in both.
